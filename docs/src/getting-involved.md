# Getting involved

PostgSail is built by boaters for boaters, and every contribution helps, code or not.

- **Report a bug or suggest a feature:** open a [GitHub issue](https://github.com/xbgmsharp/postgsail/issues).
- **Ask and help others:** join the community on [Discord](https://discord.gg/uuZrwz4dCS).
- **Improve the documentation:** every page has an edit button that opens it on GitHub. The pages are Markdown files in [`docs/src`](https://github.com/xbgmsharp/postgsail/tree/main/docs/src).
- **Translate the web app:** it's available in English, French, Spanish, German and Portuguese. The translation files are in the [web app repository](https://github.com/xbgmsharp/vuestic-postgsail/tree/main/src/i18n/locales).
- **Contribute code:** set up your environment with [Development](development.md), then follow [Contributing](contributing.md).
- **Sponsor the project:** support hosting and development through [GitHub Sponsors](https://github.com/sponsors/xbgmsharp).
